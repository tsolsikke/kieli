# kieli-cli の見本。上限を 15 バイト(ひらがなで 5 文字)にして流す(docs/try-kieli-cli.md)。
# 1. 起動したときは直接入力のモード。文字はアプリへ渡す(渡した)。
"a"
# 2. ひらがなのモードにする(モード)。今と同じモードのキーは、何もしない(何もしなかった)。
<Hiragana> <Hiragana>
# 3. ひらがな:kana は かな。Enter で確定する(確定)。
"kana" <Enter>
# 4. ん:nn と n' は ん。n の後に子音が来たら ん。確定のときの末尾の n も ん。
"nn" "n'a" <Enter>
"kanji" <Enter>
"hon" <Enter>
# 5. 促音:子音を重ねると っ。tch も っ。
"kitte" <Enter>
"matcha" <Enter>
# 6. 小書き:x の形と l の形の両方。xka はカタカナの ヵ。
"xa" "li" "xtu" "lya" <Enter>
"xka" <Enter>
# 7. 記号:[ ] - , . は 「 」 ー 、 。。
"[a]" <Enter>
"a-,." <Enter>
# 8. 大文字・数字・ほかの記号は、打ったまま全角で残す。
"A1!" <Enter>
# 9. 未定義の綴り:先頭の 1 文字を英字のまま残し、残りを照らし直す。
"qza" <Enter>
# 10. Backspace:保留のローマ字があればその最後の 1 文字、無ければ表示の最後の 1 文字を消す。
"kya" <BS> "ky" <BS> <BS> <BS>
# 11. Esc:未確定文字を全部捨てる(取消)。
"sakana" <Esc>
# 12. 未確定文字があるときの Space と F7 は変換のキー、左右と上下も取っておく(未対応)。未確定文字は残る。
"ka" <Space> <F7> <Left> <Up> <Enter>
# 13. 未確定文字が無いときの Space は、全角の空白を確定する。
<Space>
# 14. Kieli が使わないキー(Ctrl+s)は、確定してからアプリへ渡す(consumed=no)。
"ka" <Ctrl+s>
# 15. モードの切り替え:未確定文字があれば確定してから切り替える。直接入力のモードでは文字を渡す。
"ka" <Toggle> "a" <Toggle>
# 16. 直接入力の欄:パスワードの欄に移ると、未確定文字を確定せずに捨て、キーを渡す。ふつうの欄に戻ると元のモード。
"ka" <Field:password> "pw" <Field:normal> "a" <Enter>
# 17. 入力先を失う:未確定文字を取り消し、モードは保つ。
"ka" <Leave> "a" <Enter>
# 18. 上限を越える:あいうえお(15 バイト)の後の k は受け付けない(上限を越えた)。Backspace は使える。
"aiueok" <BS> <Enter>
